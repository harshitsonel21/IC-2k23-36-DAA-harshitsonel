## Requirements
- Python 3.8 or later
- No external packages required

## Run in Python IDLE
1. Extract the ZIP file.
2. Open the required `.py` file in IDLE.
3. Select **Run → Run Module** (or press **F5**).
4. Enter the values requested in the shell.

## Important
Binary search requires the input list to be sorted in ascending order.
Replace `RollNo` and `Your_Name` in the repository name with your actual roll number and name before uploading to GitHub.
